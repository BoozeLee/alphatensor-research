# Security Policy

## Supported Versions

This is a research repository. Only the latest commit on `main` is maintained.

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Report privately via GitHub's [Security Advisories](../../security/advisories/new) feature,
or email: bakerstreetbandit@zohomail.eu

Expected response time: within 7 days.
